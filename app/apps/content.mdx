### The Booth
#### mobile app to get live scores, data, and more for sports
I was tired of using ESPN's app to check scores and stats for my favorite teams, so I built my own.
It's a pretty simple app that lets you track scores, stats, and more for your favorite teams. You can 
also view historic information like previous schedules / seasons, athlete info and stats, and see rankings / standings.

At launch it supports NFL and college football, but I'm working on adding more sports. Next on the list are PGA golf and MLB / College baseball.

#### built with
- App: React Native + Expo, Unistyles
- Backend: Hono + Upstash, hosted on Cloudflare Workers

### Watchlist
#### mobile app to track the movies you want to watch
This is a simple app that lets you track the movies you want to watch. You can add movies to your watchlist,
and then mark them as watched when you're done.
It uses the TMDB API to get movie data, and it has a few other features like 
searching for movies, and viewing your watchlist.

This started because I had a note on my phone with hundreds of movies I wanted to watch and 
everytime I wanted to watch a movie, I had to scroll through the list. This was a fun little project that I built in a few days, 
and it ended up being a lot more useful than I thought it would be.

#### built with
React Native + Expo, Drizzle
